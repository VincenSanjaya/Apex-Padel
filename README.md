🎾 Apex Padel
Personal Match Tracker & Dynamic Rating System

Apex Padel adalah aplikasi pelacakan olahraga personal berbasis Flutter yang dirancang khusus untuk para pemain Padel. Aplikasi ini tidak hanya berfungsi sebagai jurnal pencatatan skor, tetapi juga dilengkapi dengan algoritma Rating Engine dinamis (skala 0.0 - 10.0) yang berfluktuasi secara otomatis berdasarkan performa, selisih skor, dan format pertandingan.

Dibangun dengan antarmuka mode gelap (dark mode) yang sporty dan minimalis, Apex Padel memberikan pengalaman pencatatan data yang cepat di lapangan, sekaligus menyediakan visualisasi analitik untuk melacak progres tingkat keahlian (skill level) dan metrik kemenangan dari waktu ke waktu.

✨ Core Features
Dynamic Rating Engine: Sistem perhitungan skor cerdas yang menyesuaikan penambahan atau pengurangan poin rating berdasarkan dominasi pertandingan (selisih game atau poin).

Dual Scoring Formats: Mendukung pencatatan dua mode pertandingan:

Traditional: Format set standar (misal: 6-4, 7-5).

Quick Match (Race to Points): Format poin beruntun yang sering digunakan untuk rotasi ganda (misal: 21-16).

Partner & Opponent Analytics: Sistem pelacakan rekan satu tim (doubles partner) untuk menganalisis persentase kemenangan (win rate) spesifik saat berpasangan dengan pemain tertentu.

Seamless Offline Storage: Penyimpanan basis data lokal yang sangat cepat untuk memastikan riwayat pertandingan tidak pernah hilang.

Programmatic Motion UI: Dilengkapi dengan custom animated splash screen dan transisi antarmuka yang mulus menggunakan native motion system.
